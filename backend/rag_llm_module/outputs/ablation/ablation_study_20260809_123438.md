### Why PPA Outperforms Raw Prompting

| PPA Feature | Impact |
| :--- | :--- |
| Versioned templates (v3) | Consistent quality requirements enforced per prompt |
| Subject addendum injection | Physics/Biology/Chemistry-specific constraints applied automatically |
| Placeholder validation | Missing variables caught before LLM call — no silent failures |
| Context grounding enforcement | Instructions explicitly restrict LLM to retrieved context only |
| Retry + fallback architecture | Guaranteed output even on LLM failure |

> Without PPA: Raw prompt has no structure enforcement, no subject-specific rules, no versioning,
> and no validation — resulting in lower structure scores and higher hallucination risk.
